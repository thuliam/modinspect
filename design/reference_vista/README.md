# VISTA.IO design study

Static study of the dark, monospace "technology company" reference: home, Services (solutions.html), Mission/Story (vision.html) and Blog (blog.html), with the shared nav and mailing-list footer.

- Original code written from screenshots; no code, text or images copied from the reference.
- Open `index.html` directly, or run `php -S 127.0.0.1:8124` in this folder.
- Font: IBM Plex Mono is loaded from Google Fonts at view time (falls back to system monospace). Self-host before any production use.
- The mailing-list form is a demo and sends nothing. Placeholder copy only.
- Not part of the ModInspect app. The adopted ModInspect direction is DL-016, which follows this style (docs/DECISION_LOG.md).
