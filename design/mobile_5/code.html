Buying Guide 5 MIN READ

ซื้อการ์ดจอมือสอง ต้องเช็กอะไรบ้าง?

คู่มือเจาะลึกการเลือกซื้อ GPU มือสองอย่างมือโปร พร้อม Checklist ตรวจสอบสภาพและวิธีเลี่ยงโดนโกง

  • Checklist ตรวจสภาพภายนอก
  • การทำ Benchmark และ Stress Test
  • สัญญาณอันตราย (Red Flags)
  • ราคากลางและการรับประกัน
fact_check

1. Checklist ตรวจสภาพภายนอก

visibility

ตรวจสอบคราบเกลือและสนิม

ส่องดูตามซิงค์ระบายความร้อนและน็อต หากมีคราบขาวหรือสนิมเขียว แสดงว่าเคยใช้งานในที่ชื้นสูง

memory

วอยด์ประกัน (Warranty Void)

ตรวจสอบสติกเกอร์หัวน็อตว่ายังอยู่ครบไหม ถ้าขาดแปลว่าเคยถูกแกะเพื่อเปลี่ยนซิลิโคนหรือซ่อม

toys

สภาพพัดลม

ลองหมุนพัดลมด้วยมือ ต้องหมุนลื่นไม่มีเสียงกึกกัก หรือแกนพัดลมไม่แกว่ง

warning

2. สัญญาณอันตราย (Red Flags)

  • dangerous ราคาถูกผิดปกติ (Too good to be true) - มักจะเป็นการ์ดผ่านการขุดหนักหรือการ์ดปลอม
  • dangerous ไม่ยอมให้ผ่านกลาง หรือนัดรับ - เสี่ยงโดนโกงเงินโอนมากที่สุด
  • dangerous มีรอยไหม้หรือคราบน้ำมันซึม - เป็นสัญญาณว่าภาคจ่ายไฟเสื่อมสภาพจากการใช้งานหนัก
