# ชุดเรื่องที่รอพี่ตัดสินใจ (LS-28)

รวมทุกเรื่องที่ค้างอยู่ใน `docs/SESSION_HANDOFF.md` ให้ตอบทีเดียว แต่ละข้อบอกว่าผลคืออะไร ถ้าไม่ตอบจะค้างอะไร และข้อเสนอของผม ตอบสั้นได้ เช่น "1 ใช่ 2 ยังก่อน"
ทุกข้อเป็นการตัดสินใจของพี่ ผมไม่ได้ทำข้อไหนไปล่วงหน้า

## ที่ผมปิดให้แล้วใน LS-28

- เครื่องตรวจ alias ที่เสี่ยงพาไปผิดรุ่น: `php cli/alias_audit.php` (อ่านอย่างเดียว) บน DEV พบ 239 alias, ซ้อนกันแบบรุ่นฐานกับรุ่น Ti/Super 23 จุด และเลขล้วน 13 จุด ไม่มีชื่อซ้ำกับสินค้าอื่น ผลนี้เป็น "รายการให้คนดู" ไม่ใช่ข้อผิดพลาด เพราะรุ่นฐานกับรุ่นต่อท้ายใช้เลขเดียวกันโดยธรรมชาติ
- ชุดค้นหามาตรฐานเพิ่มเป็น 49 คำค้น ผ่านครบ 45/45 และไม่มีสิ่งที่ไม่ควรเจอ 4/4 บน DEV
- บันทึกผลหลังดูผล Deal Checker (ซื้อ/ต่อรอง/ไม่ซื้อ และราคาที่จ่ายจริง ไม่บังคับ) ไม่มีชื่อหรือข้อมูลติดต่อ และไม่แตะราคากลาง
- ตรวจหน้าหลักที่ 375 และ 768 พิกเซล ไม่มีการเลื่อนแนวนอน (ยังไม่ได้ทดสอบ screen reader)
