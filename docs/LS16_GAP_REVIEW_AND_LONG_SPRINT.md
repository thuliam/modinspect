## 3. ทิศทาง Front-end ที่ทันสมัยขึ้น แต่คง CI

CI ที่ต้องคง: พื้น `#0a0d14` + ไลม์ `#bbf246`, ฟอนต์ Plus Jakarta Sans + Prompt, เครื่องหมาย slash หน้าหัวข้อ, โลโก้ lockup, motion แบบ full/calm

หลักที่ใช้ (ไม่ผิดกฎ "ห้ามเขียน CSS/JS เอง"):
1. **ใช้ของที่มีอยู่ซ้ำ** — การ์ดหมวด `.mi-cat`, ชิป `.mi-category-chips`, ระบบ reveal/count-up ใน `site.js` มีโหมด calm อยู่แล้ว ใส่ให้ทุกหน้าที่ยังไม่มี
2. **ใช้ความสามารถของ library** — Bootstrap (scrollspy, collapse, tooltip, toast), Chart.js
3. **ไลม์ใช้น้อย** — ปุ่มหลักหนึ่งปุ่ม, ตัวเลขสำคัญหนึ่งตัวต่อหน้า

ข้อเสนอที่ใหญ่กว่ากาว (ต้องให้เจ้าของเลือกก่อน ตามกฎ UI):

| # | ข้อเสนอ | ตัวอย่างสิ่งที่เปลี่ยน |
|---|---|---|
| D-1 | Home แบบ bento grid | ส่วน "ทำไมต้อง…" + ตัวเลข + ขั้นตอน รวมเป็นตารางการ์ดขนาดไม่เท่ากัน แทนการเรียงแถวละ 4 ใบเท่ากัน |
| D-2 | หัวหน้าสินค้าแบบ "การ์ดราคาใหญ่" | ช่วงราคา + แถบช่วง + ปุ่ม Deal Checker เป็นจุดเด่นเดียวของหน้า, ข้อมูลอื่นย้ายเป็นแท็บ |
| D-3 | Template สำเร็จรูป | ถ้าเจ้าของมี template (แบบ DropX ของหลังบ้าน) ให้ส่งมา จะใช้ตามนั้นไม่เลียนแบบเอง |
