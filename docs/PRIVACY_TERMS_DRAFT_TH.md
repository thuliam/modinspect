# ร่างนโยบายความเป็นส่วนตัวและข้อกำหนดการใช้งาน (ภาษาไทย)

**สถานะ: ฉบับร่างให้เจ้าของตรวจ ยังไม่ได้อนุมัติ และยังไม่ถูกใส่ในหน้าเว็บใดๆ** (เช็กลิสต์ beta ข้อ E-1)
ร่างนี้ไม่ใช่คำแนะนำทางกฎหมาย ควรให้ผู้เชี่ยวชาญด้านกฎหมายและ PDPA ตรวจก่อนใช้จริง ข้อความในวงเล็บเหลี่ยม `[...]` คือสิ่งที่เจ้าของต้องกำหนดเอง ผมไม่ได้เดา

ข้อเท็จจริงเกี่ยวกับระบบในร่างนี้ตรวจจากโค้ด ณ 2026-11-17 และระบุที่มาไว้ท้ายร่าง ถ้าระบบเปลี่ยน ต้องตรวจร่างนี้ใหม่

---

## นโยบายความเป็นส่วนตัว

**ผู้ให้บริการ:** [ชื่อบุคคลหรือนิติบุคคลที่เป็นผู้ควบคุมข้อมูล] ติดต่อได้ที่ [อีเมลหรือช่องทางติดต่อ]

### ข้อมูลที่เราเก็บ
1. **การใช้งานทั่วไป (ดูราคา ค้นหา อ่านวิธีคำนวณ):** ไม่ต้องสมัครสมาชิก เว็บไซต์ใช้คุกกี้เซสชันที่จำเป็นต่อการทำงานของแบบฟอร์ม (ป้องกันการส่งซ้ำและการปลอมแปลงคำขอ) ไม่ใช้สคริปต์วิเคราะห์หรือโฆษณาของบุคคลที่สาม
2. **เครื่องมือเช็กดีล (Deal Checker):** เมื่อคุณกดประเมิน ระบบบันทึกสินค้าที่เลือก ราคาที่คุณกรอก สภาพ ระยะประกันที่เหลือ ตัวเลือกกล่องหรือใบเสร็จ และผลการประเมิน พร้อมรหัสสุ่มสำหรับเปิดหน้าผลลัพธ์ ระบบไม่ขอชื่อ เบอร์โทร หรืออีเมลในขั้นตอนนี้ มีช่องยินยอมให้ใช้ข้อมูลที่ไม่ระบุตัวตนเพื่อปรับปรุงบริการ และจะบันทึกคำตอบของช่องนั้นไว้
3. **เครื่องมือจัดสเปก (Build):** ระบบบันทึกงบประมาณ การใช้งาน และชิ้นส่วนที่ประเมิน พร้อมรหัสสุ่ม ไม่ขอข้อมูลที่ระบุตัวตน
4. **ที่อยู่ IP:** ใช้จำกัดจำนวนคำขอของฟอร์มสาธารณะ โดยเก็บเป็นชื่อไฟล์แบบแฮชในโฟลเดอร์แคชของเซิร์ฟเวอร์ ไม่เก็บ IP ของผู้เข้าชมทั่วไปในฐานข้อมูล [เจ้าของกำหนดระยะเวลาล้างไฟล์แคช: เครื่องมือ `cli/retention_purge.php` พร้อมใช้เมื่อกำหนดแล้ว]
5. **ผู้ดูแลระบบ:** บัญชีผู้ดูแลมีอีเมลและรหัสผ่านที่จัดเก็บแบบแฮช ระบบบันทึกความพยายามเข้าสู่ระบบและที่อยู่ IP เพื่อความปลอดภัย

### ข้อมูลผู้ขายในตลาดมือสอง
ข้อมูลราคาบางส่วนมาจากประกาศขายสาธารณะที่ทีมงานจดบันทึกเอง ระบบออกแบบให้เก็บเฉพาะข้อมูลที่จำเป็นต่อการคำนวณราคา คือหัวข้อประกาศ ราคาเสนอขาย วันที่ และลิงก์ประกาศ ไม่เก็บชื่อผู้ขาย เบอร์โทร ที่อยู่ที่ชัดเจน ข้อความแชท หรือรูปโปรไฟล์ ลิงก์ประกาศและข้อมูลดิบไม่แสดงต่อสาธารณะ

### วัตถุประสงค์และฐานทางกฎหมาย
เพื่อให้บริการเช็กราคาและประเมินดีล ป้องกันการใช้งานในทางที่ผิด และปรับปรุงความถูกต้องของข้อมูลราคา [ฐานทางกฎหมายตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562: ผู้เชี่ยวชาญกำหนด]

### การเปิดเผยข้อมูล
ไม่ขายข้อมูล ไม่ส่งข้อมูลให้บุคคลที่สามเพื่อการโฆษณา ผู้ให้บริการโฮสติ้ง [ชื่อผู้ให้บริการ, ที่ตั้งเซิร์ฟเวอร์] ประมวลผลข้อมูลในฐานะผู้รับจ้างโฮสต์

### ระยะเวลาเก็บและสิทธิของคุณ
ระยะเวลาเก็บผลเช็กดีลและผลจัดสเปก: [เจ้าของกำหนด] คุณขอให้เข้าถึง แก้ไข ลบ หรือคัดค้านการใช้ข้อมูลที่เกี่ยวกับคุณได้ที่ [ช่องทางติดต่อ] เนื่องจากไม่ได้เก็บข้อมูลระบุตัวตนในเครื่องมือสาธารณะ ผู้ให้บริการอาจต้องขอรหัสผลลัพธ์ (ลิงก์หน้าผลลัพธ์) เพื่อค้นหาข้อมูลของคุณ

## ข้อกำหนดการใช้งาน

1. **ลักษณะของข้อมูล:** ราคาที่แสดงเป็นราคาเสนอขายที่รวบรวมจากประกาศ ไม่ใช่ราคาที่ซื้อขายสำเร็จ ช่วงราคาและคะแนนความมั่นใจเป็นการคำนวณจากตัวอย่างที่มี ไม่ใช่การประเมินสินค้าชิ้นใดชิ้นหนึ่ง
2. **ไม่ใช่คำแนะนำ:** ผลจาก Deal Checker และเครื่องมือจัดสเปกเป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่คำแนะนำทางการเงิน และไม่รับประกันว่าสินค้าจริงตรงตามประกาศ ผู้ใช้ควรตรวจสภาพสินค้าด้วยตนเองก่อนซื้อขาย
3. **ไม่ใช่ตัวกลางซื้อขาย:** เว็บไซต์ไม่ขายสินค้า ไม่เก็บเงิน ไม่เป็นตัวกลางหรือผู้รับรองการซื้อขายระหว่างผู้ใช้
4. **ความถูกต้อง:** ข้อมูลอาจล่าช้า ไม่ครบ หรือคลาดเคลื่อน ระบบแสดงระดับความมั่นใจและที่มาของข้อมูลในหน้าสินค้า ผู้ให้บริการไม่รับผิดต่อความเสียหายที่เกิดจากการใช้ข้อมูลโดยไม่ตรวจสอบเพิ่ม [ขอบเขตความรับผิดตามกฎหมาย: ผู้เชี่ยวชาญกำหนด]
5. **การใช้งานที่ห้าม:** ห้ามใช้ระบบอัตโนมัติดึงข้อมูลจำนวนมากโดยไม่ได้รับอนุญาต ห้ามพยายามหลีกเลี่ยงการจำกัดคำขอ และห้ามส่งข้อมูลเท็จเพื่อบิดเบือนผล
6. **เครดิตรูปภาพและโลโก้:** รูปสินค้าและโลโก้ที่แสดงเป็นของเจ้าของสิทธิ์ตามที่ระบุไว้ในหน้าวิธีคำนวณ [เจ้าของยืนยันสิทธิ์ของโลโก้และงานแบรนด์ก่อนเปิดใช้: เช็กลิสต์ E-3]
7. **การเปลี่ยนแปลง:** ผู้ให้บริการอาจแก้ไขข้อกำหนดและนโยบายนี้ โดยแสดงวันที่ปรับปรุงล่าสุดบนหน้านี้ [วันที่ประกาศใช้]
8. **กฎหมายที่ใช้บังคับ:** [กฎหมายไทย และศาลที่มีเขตอำนาจ: ผู้เชี่ยวชาญกำหนด]

## ที่มาของข้อเท็จจริงในร่าง (ตรวจจากโค้ด 2026-11-17)
| ข้อความ | ตรวจจาก |
|---|---|
| ไม่มีสคริปต์วิเคราะห์หรือโฆษณาของบุคคลที่สาม | ค้นคำ gtag, analytics, googletagmanager, fbq ใน `app/Views` และ `public` (ไม่รวม vendor) ไม่พบนอกจากหน้าแอดมิน `review-analytics` ที่เป็นชื่อหน้าภายใน |
| Deal Checker เก็บรายการข้างต้น | `app/Controllers/DealCheckerController.php::store`, `app/Models/DealCheck.php`, ตาราง `deal_checks` (มีคอลัมน์ `consent_to_anonymous_observation`) |
| Build เก็บงบประมาณ การใช้งาน ชิ้นส่วน | `app/Models/SpecBuild.php` |
| IP ของผู้เข้าชมทั่วไปเป็นชื่อไฟล์แคชแบบแฮช | `app/Services/Http/RateLimiter.php` (`hash('sha256', $client)`) |
| IP ของผู้ดูแลถูกบันทึก | `app/Services/Auth/AuthService.php` (`audit_logs.ip_address`, `recordLoginAttempt`) |
| ไม่เก็บชื่อผู้ขาย เบอร์ ที่อยู่ แชท รูปโปรไฟล์ และข้อมูลดิบไม่เปิดสาธารณะ | `AGENTS.md` (นโยบายโครงการ), `tests/` ที่ตรวจหน้าหลักฐาน และ `CaptureMethod` (ปฏิเสธเบอร์โทรในหัวข้อและลิงก์โปรไฟล์) |

## สิ่งที่เจ้าของต้องตัดสินก่อนใช้ร่างนี้
1. ชื่อผู้ควบคุมข้อมูลและช่องทางติดต่อ
2. ระยะเวลาเก็บผลเช็กดีล ผลจัดสเปก และไฟล์แคชจำกัดคำขอ
3. ผู้ให้บริการโฮสติ้งและที่ตั้งเซิร์ฟเวอร์ (ตามที่ตกลงไว้คือ HostAtom, DL-014)
4. ฐานทางกฎหมายและขอบเขตความรับผิด ต้องให้ผู้เชี่ยวชาญตรวจ
5. จะแสดงหน้าเหล่านี้ที่ไหน (ท้ายหน้า, หน้า Deal Checker) ซึ่งเป็นงานหน้าเว็บที่ต้องขออนุมัติแยกตามกฎ UI
