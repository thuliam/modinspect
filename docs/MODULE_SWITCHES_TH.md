# สวิตช์เปิด/ปิดโมดูล (คู่มือพี่ เปิดครั้งเดียวทำได้โดยไม่ต้องอ่านโค้ด)

วันที่ 2026-11-20 · ซ้อมแล้วด้วย `tests/module_switch_rehearsal_test.php` (ปิด → 404, เปิดพร้อมของที่ต้องมี → ใช้ได้, ปิดอีกครั้ง → 404) และตรวจโดย `php cli/env_preflight.php` บน host

## ขั้นตอนเปิด (ใช้ได้กับทุกโมดูลที่มีสวิตช์)

1. **สำรองฐานข้อมูล** (`php cli/db_backup.php` หรือส่งออกจาก phpMyAdmin)
2. **ลง migration** ที่ระบุ (ถ้ายังไม่ได้ลง) ตามลำดับเลข ผ่าน phpMyAdmin หรือ `php cli/migrate.php database/migrations/<ไฟล์>` ลงซ้ำไม่ได้โดยไม่มี error เพราะเป็น `CREATE TABLE` ให้ลงทีละไฟล์และจดไว้ว่าลงแล้ว
3. **สร้าง key** (เฉพาะโมดูลที่ต้องมี) พี่รันเองในเครื่องของพี่: `php -r "echo bin2hex(random_bytes(24)), PHP_EOL;"` จะได้ 48 ตัวอักษร แล้วใส่ใน `.env` บน host (ห้ามส่งให้ผมหรือใส่ในแชต)
4. **ตั้งค่าใน `.env`** ตามตาราง แล้วรัน `php cli/env_preflight.php` ต้องไม่มี FAIL (ถ้าเปิดสวิตช์โดยไม่มี key จะขึ้น FAIL ชื่อโมดูลนั้น)
5. **ล้างแคชที่เกี่ยวข้อง** ถ้ามี (sitemap แคช 10 นาที)
6. **ลองเอง 1 รอบ** ตามรายการทดสอบท้ายตาราง แล้วค่อยบอกคนอื่น

## ขั้นตอนปิดกลับ (ฉุกเฉินใช้เวลาไม่ถึงหนึ่งนาที)

แก้ `.env` ให้สวิตช์เป็น `false` (หรือลบบรรทัด) ทุกเส้นทางของโมดูลนั้นตอบ 404 ทันที และลิงก์ในเมนูหายไป **ข้อมูลที่เก็บไว้ไม่ถูกลบ** (ถ้าต้องการลบ ใช้ `php cli/retention_purge.php` ซึ่งมี dry-run ก่อนเสมอ ดูหัวข้อถัดไป) ไม่ต้อง rollback migration

## ระยะเก็บข้อมูล (พี่เลือกตัวเลข ผมไม่ตั้งค่าเริ่มต้นให้)

```bash
php cli/retention_purge.php --community-days=90          # รายงานชุมชนที่ไม่ผ่านหรือสแปม นับจากวันตัดสิน
php cli/retention_purge.php --seller-pending-days=90     # รายงานผู้ขายที่ค้างหรือไม่ผ่าน พร้อมไฟล์หลักฐาน (verified และ disputed ไม่ถูกลบ)
php cli/retention_purge.php --forum-days=90              # เนื้อหากระทู้ที่ถูกซ่อน (เนื้อหาที่แสดงอยู่ไม่ถูกลบ)
```

ทุกคำสั่งเป็น dry-run จนกว่าจะใส่ `--apply` และขั้นต่ำ 7 วัน ใส่ cron วันละครั้งบน host เองหลังพอใจกับตัวเลขที่ dry-run แสดง

## รายการทดสอบหลังเปิด (ทำเองได้ 5 นาทีต่อโมดูล)

- **สมาชิก:** กดล็อกอินด้วยบัญชีทดสอบ เห็นชื่อบนหน้า `/account` ออกจากระบบได้ ลบบัญชีได้
- **รายงานชุมชน:** เปิด `/report/<slug รุ่น>` เห็นฟอร์ม ส่งรายงานทดสอบ 1 รายการ เห็นใน `/admin/community-reports`
- **ชุมชน:** ล็อกอินสมาชิก ตั้งกระทู้ทดสอบ ตอบ แจ้งผู้ดูแลด้วยบัญชีที่สอง สามบัญชีแจ้งแล้วเนื้อหาถูกซ่อน เห็นใน `/admin/community-moderation`
- **เช็กผู้ขาย:** ล็อกอินสมาชิก ส่งรายงานเบอร์ทดสอบ 1 รายการ ผู้ตรวจกด verified ค้นเบอร์เดียวกันเห็น "1 รายงานที่ตรวจแล้ว" ส่งโต้แย้ง ผู้ตรวจแก้ไข **ห้ามใช้เบอร์ของคนจริงตอนทดสอบ**
- **Seller:** สมาชิกสร้างประกาศ แอดมินอนุมัติ เห็นที่ `/listings/<uuid>` เมื่อ `SELLER_LISTINGS_PUBLIC=true`

## สิ่งที่ผมทำให้แล้วและยังไม่ได้ทำ

| ทำแล้ว | ยังไม่ทำ (รอพี่/host) |
|---|---|
| โค้ดทุกโมดูล, เทสต์เปิด/ปิด, preflight ตรวจสวิตช์ที่ไม่มี key, คำสั่งลบตามระยะเก็บ | ลง migration บน DEV/host, สร้าง key, ตั้ง `.env` บน host, ข้อความที่ต้องอนุมัติ, ทนาย (HG-14), cron, รัน preflight บน host |
