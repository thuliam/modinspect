# งานที่รอพี่ (ว่างเมื่อไรค่อยทำ)

อัปเดต 2026-11-28 หลังทำ LS-89 ทาง 3 · agent อัปเดตไฟล์นี้เมื่อจบรอบงาน และเตือนข้อที่ค้างสั้นๆ ท้ายรายงาน
ติ๊ก `[x]` หรือบอกในแชตว่าข้อไหนเสร็จแล้ว

## ด่วน (กระทบเว็บจริง)
- [ ] **A1 อนุมัติขึ้นของที่ทำแล้วไปเว็บจริง** (สาขา `ls89-backend` รวมการแก้ราคา) เว็บจริงยังมี 2 ปัญหา: หน้า i5-8400 แสดงราคาผิด และหน้าตรวจรายการในหลังบ้านแสดงซอร์สโค้ด ใช้เวลา 1 นาที: ตอบในแชต
- [ ] **A2 เปลี่ยนรหัสผ่านฐานข้อมูล และรหัสที่อยู่ในไฟล์ LINE export**
- [ ] **A3 ข้อความความเป็นส่วนตัวและข้อกำหนด:** กรอกช่องว่างใน `docs/PRIVACY_TERMS_DRAFT_TH.md` แล้วให้ผู้รู้กฎหมายตรวจ (เว็บจริงยังไม่มีหน้า `/privacy`)

## หลังขึ้นเว็บจริง
- [ ] **A4 อนุมัติลง migration 038 และ 039 กับฐานจริง** (เพิ่มตารางอย่างเดียว สำรองฐานก่อน) โค้ดใหม่ทำงานได้แม้ยังไม่ลง
- [ ] **A5 อนุมัติคำนวณราคาและกราฟใหม่บนฐานจริง** ลองแบบอ่านอย่างเดียวแล้ว: ราคากลางไม่เปลี่ยน กราฟเปลี่ยน 8 จุด เพิ่ม 19 ลบ 1
- [ ] **A6 ดูรุ่นรหัส 229:** กราฟเดือน พ.ย. จะเปลี่ยนจาก 2,190 เป็น 1,400 (ตัวอย่าง 3 เป็น 7) ควรเปิดดูประกาศก่อนเชื่อ
