# เขียนบทความลง Blog (คู่มือสั้นสำหรับพี่)

วันที่ 2026-11-20 · เขียนที่ `/admin/articles` (ต้องมีสิทธิ์ products.manage) ผู้อ่านเห็นที่ `/blog` เฉพาะบทความที่สถานะ **published** และเวลาเผยแพร่ถึงแล้ว (ร่างและ archived ตอบ 404)

## ตัวอักษรพิเศษที่ใช้ได้ในเนื้อหา

เนื้อหาเป็นข้อความธรรมดา ระบบ escape ทุกอย่างก่อน แล้วจึงแปลงเครื่องหมายด้านล่างเป็นรูปแบบ (พิมพ์ HTML หรือสคริปต์ลงไปไม่มีผล)

| พิมพ์ | ได้ |
|---|---|
| เว้นบรรทัดว่าง | ย่อหน้าใหม่ |
| `## หัวข้อใหญ่` / `### หัวข้อย่อย` | หัวข้อ |
| `- ข้อความ` (หลายบรรทัดติดกัน) | รายการจุด |
| `> ข้อความ` | ข้อความอ้างอิง |
| `**ตัวหนา**` | ตัวหนา |
| `[ข้อความ](https://example.com)` หรือ `[ข้อความ](/price)` | ลิงก์ (รับเฉพาะ http, https หรือเส้นทางในเว็บนี้) |
| `{{price:ชื่อ-slug-ของรุ่น}}` บนบรรทัดของตัวเอง | การ์ดช่วงราคาสดของรุ่นนั้น (ถ้ารุ่นยังไม่มีราคา การ์ดบอกว่ายังไม่มี) |

slug ดูได้จาก URL ของหน้ารุ่น เช่น `/price/nvidia-geforce-rtx-3070` → `{{price:nvidia-geforce-rtx-3070}}` การ์ดดึงตัวเลขเดียวกับหน้ารุ่น จึงไม่มีทางพูดเกินกว่าหน้ารุ่น

## ร่างบทความ "ภาพตลาดวันนี้" จากตัวเลขจริง

```bash
php cli/market_snapshot_draft.php --out=storage/import/market-today.txt
```

ได้ไฟล์ที่มีหัวข้อ slug สรุป และเนื้อหาพร้อมการ์ดราคา คัดลอกไปวางในฟอร์มบทความ ตั้งสถานะเป็น draft ตรวจแล้วค่อยเปลี่ยนเป็น published ข้อความในร่างเป็นแม่แบบตายตัวจากตัวเลขที่มี ไม่ใช้ AI เขียน และไม่อ้างการเปลี่ยนแปลงตามเวลาจนกว่าจะมีข้อมูลหลายช่วง

## ตั้งเวลาเผยแพร่

ตั้งสถานะ published แล้วแก้วันที่เผยแพร่เป็นเวลาในอนาคต บทความจะยังไม่โผล่จนกว่าถึงเวลา (ฟอร์มปัจจุบันตั้งเวลาปัจจุบันให้เมื่อเผยแพร่ ถ้าต้องการเวลาในอนาคตให้แจ้งผม จะเพิ่มช่องให้)

## ข้อควรระวัง

- บทความที่เขียนเรื่องการซื้อขายควรเล่าสิ่งที่เกิดขึ้นหรือข้อเท็จจริง ไม่เรียกบุคคลว่าโกงหรือมิจฉาชีพ และไม่ใส่ชื่อ เบอร์ หรือบัญชีของใคร
- รูปประกอบ: ตอนนี้บทความใช้ภาพแบรนด์เป็นค่าเริ่มต้นตอนแชร์ ถ้าต้องการรูปปกต่อบทความ ให้บอกที่เก็บไฟล์ภาพที่พี่มีสิทธิ์ใช้
