# LS-17: แผนงานยาวที่ทำได้เองโดยไม่ต้องรอเจ้าของ

วันที่ 2026-11-19 · ต่อจาก LS-16 (`b426d96`) · เป้าหมาย: ทำงานต่อเนื่องหลายชั่วโมงโดยพี่ไม่ต้องตอบอะไรระหว่างทาง แล้วรวมเรื่องที่ต้องตัดสินไว้ท้ายแผน

## กติกา (เหมือนเดิมทุกข้อ)

- ไม่ deploy, ไม่แตะ host, ไม่เขียนฐาน DEV ร่วม (ใช้ฐาน test เท่านั้น), ไม่ push/merge `main`, ไม่ใช้เงิน, ไม่ดาวน์โหลด library
- UI: ใช้ class ที่มีอยู่, Bootstrap, Chart.js ได้ ส่วน CSS/JS ใหม่ใช้ได้แค่กาวไม่กี่บรรทัด อะไรใหญ่กว่านั้นจะเขียนเป็นข้อเสนอแทน
- งานทุกชิ้นต้องมีเทสต์ และ mutation-check ถ้าเป็น logic, รันเทสต์ทั้งชุดให้ผ่าน, เปิดดูใน browser ที่ 320/375/768/1440 ถ้าแตะหน้าเว็บ
- จบแต่ละช่วงจะ commit บน `studio` และอัปเดต `PROJECT_STATUS.md` (ยังไม่ push จนกว่าพี่สั่ง)
- ถ้าเจออะไรที่ต้องให้พี่ตัดสิน จะจดไว้ในข้อ 5 แล้วทำงานชิ้นถัดไปต่อ ไม่หยุดรอ
