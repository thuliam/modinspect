# LS-62 Admin UX/UI Audit (2026-11-23)

ขอบเขต: หน้า admin 26 หน้า (ทุกหน้า GET ที่เปิดได้ด้วยบัญชีแอดมิน) วัดด้วยสคริปต์ในเบราว์เซอร์ที่ 1440px และ 375px บนเซิร์ฟเวอร์ local + ฐานทดสอบ (บัญชีทดสอบ ลบแล้ว) · สกิน DropX คงเดิม ตามที่พี่ตัดสิน · ตัวเลข "ก่อน" คือค่าที่วัดได้ก่อนแก้รอบนี้

## แก้แล้วในรอบนี้ (ต่อท้าย `public/assets/mi-dropx.css` เท่านั้น ไม่แตะ markup ยกเว้นช่องสถานะที่หน้าสินค้า)

ชุดฟอร์ม (LS-63) + ชุดแก้จาก audit: ป้ายประโยคปกติ 13px, ระยะฟิลด์ 16px บนตาราง 4px, ช่อง 38px, select2 38px, ปุ่ม 38px, หัวตาราง 12px ประโยคปกติ, ตัวเล็ก 12px ขั้นต่ำ, card padding 20px, แถบท้ายฟอร์มเป็นเส้นบาง, ช่องสถานะเป็น checkbox (Bootstrap 4.1 ไม่มี `custom-switch`), ช่องอัปโหลดไฟล์แบบ native ปรับ padding

## ปิดแล้วในรอบสอง (2026-11-23)

1. ปุ่มและลิงก์ในตารางบนมือถือสูงอย่างน้อย 40px (วัดซ้ำที่ 375px ไม่เหลือปุ่มเล็กกว่า 36px)
2. หน้า Imports: สองการ์ดความสูงเท่ากัน (`h-100`) บนกริดเดิม 7/5
3. inline style ใน view admin เหลือ 0 (เปลี่ยนเป็น class `mi-th-wide`, `mi-cell-max`, `mi-chart-box`) และมีเทสต์ `tests/admin_ui_pattern_test.php` กันไม่ให้กลับมา
4. ตัวอักษรเล็กกว่า 12px: `dt` และ `code` ปรับเป็น 12px เหลือ 0
5. Beta readiness: คอลัมน์ ID ไม่ตัดบรรทัด
6. ตรวจข้อความที่ไม่แปล: view admin มีข้อความ hard-code ไม่กี่จุด (เมนู `_nav.php` 12, community-reports 9, market-trends 8) ยังไม่ได้แปล ไม่ได้แก้ในรอบนี้
7. หน้า `/admin/ui-kit` (ฟอร์ม ตาราง สถานะว่าง) พร้อมคีย์แปล ไทย/EN

## เดิม: ยังไม่ได้แก้ (ก่อนรอบสอง)

1. **Tap target บนมือถือ:** ปุ่มแอ็กชันในตาราง DataTables สูงต่ำกว่า 32px ที่ 375px (Products/Aliases/Price Index 50 ปุ่ม, Sources 21, Users 20, Collector jobs 30) ต้องตัดสินใจว่าจะทำเป็นเมนู "..." หรือขยายปุ่ม
2. **หน้า Imports (collector-jobs):** การ์ด "Upload And Dry Run" กว้าง 60% กับ "Confirm Import" 40% ไม่ได้ใช้กริดเดียวกับส่วนอื่น, ชุดป้าย 7 ขั้นเป็นชิปเล็ก, ปุ่มแม่แบบ CSV/JSON อยู่ในหัวการ์ด ควรจัดใหม่พร้อม LS ศูนย์นำเข้า
3. **Inline style:** Products 6, Price observations 8, Review queue 8, Users 6, Aliases 3 จุด (ยังไม่ตรวจว่าจำเป็นหรือไม่)
4. **ตัวอักษรเล็ก 5 ถึง 6 จุดที่ Dashboard และ Sources** (ค่า `<small>` ภายในการ์ดไล่สีของ DropX) ต้องดูภาพก่อนเปลี่ยน เพราะเป็นดีไซน์ของเทมเพลต
5. **Beta readiness:** คอลัมน์ ID ตัดบรรทัด ("A-" / "1") ควรกำหนดความกว้างขั้นต่ำ
6. **ภาษา:** ป้ายหน้าจอผสมไทย/อังกฤษตามภาษาที่เลือก (ปุ่ม ไทย/EN) ยังไม่ได้ตรวจว่าทุกหน้ามีคำแปลครบ
7. **ยังไม่ได้ทำ:** หน้าตัวอย่าง `/admin/ui-kit` และเทสต์สแกน inline style ตามแผน LS-63

## วิธีวัดซ้ำ

เปิด local server บน `.env.testing` (ตั้ง `APP_URL` เป็นตัวเอง) แล้วใช้สคริปต์ iframe ในเบราว์เซอร์: โหลดแต่ละหน้า, วัด `getBoundingClientRect` ของช่องกรอก/ปุ่ม, `fontSize`, `textTransform`, `scrollWidth` ที่ 1440 และ 375px
