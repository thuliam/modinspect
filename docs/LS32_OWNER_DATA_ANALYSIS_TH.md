## 4. อัปเดต (ตามที่พี่สั่ง: ผลทดสอบ + กราฟแท่ง)

**ผลทดสอบ (benchmark) ขึ้นหน้าสินค้าแล้ว** (ส่วน "คะแนนประสิทธิภาพจากผู้ทดสอบ" หัวข้อ "ผลทดสอบ" ในแถบเมนูหน้า)
- ตารางใหม่ `product_benchmark_scores` (migration 029) เก็บคะแนน InnoReviews (CC BY 4.0) พร้อมที่มา ลิงก์ วันที่ข้อมูล และข้อความสัญญาอนุญาต ไม่ถูกใช้ในการคำนวณราคา
- ตัวนำเข้า `php cli/benchmark_import_innoreviews.php --category=gpu|cpu --file=<csv> [--apply]` (dry run เป็นค่าเริ่มต้น) จับคู่ด้วยชื่อแบบเข้มงวด: ชื่อต้องตรงกับรุ่นเดียวและไม่ซ้ำ ไม่เดา (รุ่น X กับ X3D, F กับไม่ใช่ F แยกกัน) ทดสอบใน `tests/benchmark_scores_test.php`
- ฐานทดสอบ: GPU จับคู่ได้ 11 จาก 11 รุ่น, CPU 10 จาก 10 รุ่น ใน catalog จริงของ DEV พบ GPU 27 จาก 29 และ CPU 26 จาก 28 (ตรวจแบบอ่านอย่างเดียว)
- ชุดไฟล์ SSD/RAM/PSU/เคส/ระบายความร้อนยังไม่ได้ทำ: ไม่มีคะแนนรวมแบบเดียวกัน (เป็นค่าวัดรายการ หน่วยต่างกัน) ต้องออกแบบแยกต่อหมวด

**กราฟแท่งเทียนราคารายเดือน** แทนกราฟเส้นเดิม
- แท่ง = Q1 ถึง Q3, ไส้ = ราคาต่ำสุดถึงสูงสุด, จุด = ราคากลาง, สีแท่ง = เขียวถ้าราคากลางขึ้นจากเดือนก่อน แดงถ้าลง, เส้นประ = Q1 และ Q3 ของเดือนล่าสุด (แนวรับ/แนวต้าน)
- วาดด้วย Chart.js เดิม (แท่งลอย) ไม่ต้องดาวน์โหลดปลั๊กอินการเงิน เพราะปลั๊กอินนั้นต้องมีตัวแปลงวันที่เพิ่มอีกตัว จึงไม่ได้ดาวน์โหลดอะไรเลย
- แท่งหมายถึงราคาประกาศขาย ไม่ใช่ราคาปิดดีล (ข้อความใต้กราฟบอกไว้แล้ว) เดือนเดียวก็เห็นเป็นแท่งเดียว
- ต้องมีเดือนที่มีตัวอย่างที่ผ่านการอนุมัติอย่างน้อย 3 รายการ ข้อมูล Facebook ยังรอตรวจ จึงยังไม่ทำให้กราฟของ RTX 3080 ขึ้นเอง
