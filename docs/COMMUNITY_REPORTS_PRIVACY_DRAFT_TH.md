# ร่างข้อความความเป็นส่วนตัวของ "แจ้งข้อมูลที่ไม่ถูกต้อง" (ร่าง ยังไม่ใช้งานจริง)

สถานะ: **ร่างให้เจ้าของตรวจ** ยังไม่แสดงบนหน้าเว็บ ฟีเจอร์ปิดอยู่ (`COMMUNITY_REPORTS_ENABLED=false`) และไม่ใช่คำปรึกษากฎหมาย
ข้อความด้านล่างเขียนจากสิ่งที่โค้ดทำจริง (`CommunityReports`, ADR-006) ถ้าพฤติกรรมเปลี่ยน ต้องแก้ข้อความให้ตรงก่อนเปิด

## ข้อความสำหรับผู้ใช้ (วางใต้ฟอร์ม)

> **แบบฟอร์มนี้เก็บอะไร**
> เก็บเฉพาะตัวเลือกและตัวเลขที่คุณเลือก เช่น ประเภทปัญหา ราคา เดือนที่ขายได้ สภาพสินค้า ไม่มีช่องพิมพ์ข้อความอิสระ ไม่ขอชื่อ เบอร์โทร อีเมล หรือที่อยู่
>
> **เรารู้จักคุณไหม**
> ไม่ เราไม่เก็บที่อยู่ IP ของคุณ เราสร้างรหัสสั้น ๆ จากที่อยู่ IP ด้วยกุญแจลับที่เปลี่ยนทุกวัน ใช้เพื่อกันการส่งซ้ำและการส่งถี่เกินไปเท่านั้น และย้อนกลับเป็นตัวคุณไม่ได้
>
> **รายงานของคุณถูกใช้อย่างไร**
> ผู้ดูแลที่เป็นคนจริงอ่านและตัดสินทุกรายงาน รายงานไม่เปลี่ยนราคาที่แสดงบนเว็บโดยตรง ถ้าคุณแจ้งราคาที่ขายได้ ผู้ดูแลอาจส่งต่อเป็น "หลักฐานรอตรวจ" ซึ่งต้องผ่านการตรวจอีกชั้นก่อนจะมีผลต่อข้อมูล และไม่ใช่ราคาตลาดโดยอัตโนมัติ
>
> **เก็บนานแค่ไหน**
> รายงานที่ไม่ผ่านหรือเป็นสแปมจะถูกลบหลังครบ [N] วันนับจากวันที่ตัดสิน รายงานที่รับแล้วเก็บไว้เป็นหลักฐานประกอบข้อมูลของรุ่นนั้น
>
> การส่งแบบฟอร์มเป็นความสมัครใจ

## ข้อที่พี่ต้องตัดสินก่อนเปิด

| # | เรื่อง | ค่าที่เสนอ |
|---|---|---|
| 1 | จำนวนวัน [N] ที่เก็บรายงานที่ไม่ผ่านและสแปม | 90 วัน (ตาม ADR-006, ขั้นต่ำที่ระบบรับคือ 7 วัน) |
| 2 | ใครเป็นผู้ตัดสินรายงาน | บทบาท reviewer หรือ admin (สิทธิ์ `reports.moderate`) |
| 3 | รายงานที่รับแล้วเก็บถาวรหรือกำหนดอายุ | เก็บ (ตอนนี้ระบบไม่ลบอัตโนมัติ) |
| 4 | ให้ทนายตรวจข้อความข้างบนพร้อมนโยบายความเป็นส่วนตัวหลักของเว็บ | แนะนำ ก่อนเปิดจริง |
| 5 | ตั้ง `COMMUNITY_REPORTS_HMAC_KEY` (สุ่มยาว 32 ตัวอักษรขึ้นไป) บนโฮสต์ | พี่สร้างเอง ผมไม่ถือ key |

## ตัวอย่างคำสั่ง cron สำหรับพี่ติดตั้งบนโฮสต์เอง (ผมไม่ได้รันอะไรบนโฮสต์)

ลองแบบไม่ลบก่อนเสมอ (ไม่ใส่ `--apply` = dry run พิมพ์จำนวนที่จะลบเท่านั้น):

```bash
php /path/to/modinspect/cli/retention_purge.php --community-days=90
```

เมื่อพอใจกับตัวเลขแล้ว ตั้ง cron วันละครั้ง (หลังสำรองข้อมูล `php cli/db_backup.php`):

```bash
17 3 * * * php /path/to/modinspect/cli/retention_purge.php --community-days=90 --apply
```

คำสั่งนี้ลบเฉพาะรายงานสถานะ `rejected` และ `spam` เท่านั้น รายงานใหม่และที่รับแล้วจะไม่ถูกแตะ
