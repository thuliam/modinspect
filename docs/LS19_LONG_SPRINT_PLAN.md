# LS-19: แผนงานยาวถัดไป (เสนอ)

วันที่ 2026-11-19 · ต่อจาก LS-18 (`598ba20`, push แล้ว, PR #6 เปิดอยู่)
กติกาเหมือน LS-17 ทุกข้อ:
- ไม่ deploy, ไม่เขียนฐาน DEV, ไม่ merge `main`, ไม่ใช้เงิน
- ดาวน์โหลด library ต้องถามก่อน
- ทุกงานต้องมีเทสต์ และตรวจใน browser
- จดเรื่องที่ต้องให้พี่ตัดสินไว้ท้ายแผน แล้วทำงานชิ้นถัดไปต่อ

## สิ่งที่ CI เพิ่งเจอ (เหตุผลที่ช่วง A มาก่อน)

งาน "Fresh install rehearsal" ที่เพิ่มใน LS-17 รันครั้งแรกหลัง push แล้ว **แดง** ที่ migration 009 (`Duplicate column name 'source_key'`)

สาเหตุ: `database/schema.sql` เป็นโครงสร้างล่าสุดครบถึง 025 อยู่แล้ว แต่ข้อมูลจาก migration บางตัวไม่ได้อยู่ในนั้น เช่น 013, 014, 018, 020, 021 ซึ่งเป็นแคตตาล็อกและสเปกผู้ผลิต
- ถ้าทำตาม runbook ปัจจุบัน ("import schema แล้วไล่ migration ทุกตัว") **host ใหม่จะพัง**
- ถ้าใช้ schema อย่างเดียว **แคตตาล็อกจะว่าง**

ดีที่เจอตอนนี้ ไม่ใช่วันขึ้นจริง CI ของ PR #6 จะแดงอยู่จนกว่าจะแก้ข้อ A1
