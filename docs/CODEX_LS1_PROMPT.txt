1. WHAT THE PROJECT IS (one paragraph)
ModInspect is a Thai-first used-PC-hardware price-check site. PHP 8.1+ custom MVC without a framework, PDO prepared statements, Bootstrap 4.1 + jQuery. The valuable asset is: Product Master + aliases + time-series price observations + evidence/provenance + deterministic versioned price snapshots. Prices are asking prices (not sold prices). Deterministic PHP code calculates prices and confidence; nothing else may write a price snapshot. Owner-collected data and community data are evidence only.
