# ModInspect Admin Assets

The admin shell adapts visual patterns from the Concept Bootstrap 4 Admin Dashboard Template by Colorlib.

Attribution:
- Concept Bootstrap 4 Admin Dashboard Template
- Original author: Colorlib
- License: MIT, as supplied with the local Concept reference template

Copied assets are limited to the local Bootstrap 4, jQuery, Font Awesome, and DataTables Bootstrap adapter files needed by the ModInspect admin UI. The Concept reference folder remains a template source and is not part of the ModInspect application.
